# MOA — 구현 설계 (2026-09-21)

사용자 요청: 매일 서울 10건, 기타 시도교육청 각각 무작위 5건의 학교 가정통신문을 수집한다.
원문과 표·양식 사례는 NAS 볼륨2에만 저장한다. 완전히 같은 파일은 한 벌만 보관한다.
GitHub h19h29-design/moa에는 코드·테스트·설명서만 올린다.

## 결정
- '개'는 학교 수나 첨부파일 수가 아니라 고유 통신문 건수. 한 통신문의 첨부는 묶는다.
- NEIS 학교기본정보 전체 목록을 정식 API 키로 동기화한다. sample 5건을 전체 목록으로 오인하지 않는다.
- 교육청 그룹은 반환된 실제 교육청 코드/이름을 사용한다. 서울 10, 기타 5. 코드 변경에도 적응한다.
- 매일 날짜+교육청을 시드로 학교를 섞고, 학교급 순환으로 표본 다양성을 보완한다.
- 공개 가정통신문 게시판을 HTML 링크 기반으로 탐색한다. 회원로그인/캡차/robots 차단 우회 없음.
- 지원되지 않는 게시판은 실패로 보고하고 다음 학교로 넘어간다. 할당량 부족을 성공으로 숨기지 않는다.
- 같은 날 다시 실행하면 저장된 지역별 실적을 빼고 부족분만 수집한다. 작업 전체는 파일락으로 직렬화한다.
- SHA-256 객체 저장소: 파일 바이트 동일 시 단일 저장. 통신문 원문 본문+자산 해시가 같으면 별칭만 기록.
  유사한 표/양식이라는 이유로 원문을 삭제하지 않는다. 날짜·숫자가 다른 정정본은 새 버전으로 보존한다.
- 학습은 로컬 표 추출/구조 패턴 집계/검색 가능한 사례 축적이다. 모델 가중치 자동 재학습이 아니다.
  원본, 미검수 후보, 사람이 승인한 정답 데이터를 분리하며 수집된 데이터는 자동 승인하지 않는다.
- PDF(텍스트/선 있는 표), HWPX(XML 표), HTML 표 분석. 이미지/스캔 PDF/구형 HWP는 원문 저장과 대기 상태.
- NAS 배포는 단일 비권한 Docker 컨테이너, /volume2/moa/data -> /data. 공개 포트 없음.
- 기본 매일 한국시간 04:00, 첫 기동 즉시 한 번 실행. 시간은 환경변수로 변경.
- 이번 환경에서 NAS 접근·Docker·실제 HTTP 실행은 불가. 코드의 네트워크 통합 테스트는 모의 응답 사용;
  실제 배포 검증은 사용자 NAS에서 doctor/run/status로 수행한다.
