# MOA 라벨 쏠림 진단과 근거 가드·이진 판별 — 2026-10-20

## 결론

근거 부족을 원문 확보 규칙으로 분리하고, 근거가 있는 구간만 정상/오류 두 선택지로
실제 추론하는 연구 경로를 구현했다. **추가 가중치 학습은 0회**다. 기존 후보 8/8 한도를
유지했다. 기존 모델의 내용 판별 능력 개선은 확인하지 못해 운영에는 연결하지 않는다.

두 선택지뿐 아니라 두 순서의 실제 추론을 같은 비중으로 평균하는 방식도 확인했다.
새 구간 후보의 개발 정확도는 35/54(64.8%)지만 정상 오탐 17/18(94.4%), 균형 정확도
50%다. 이 자료에서 전부 오류라고 답하는 기준 36/54(66.7%)보다 낮다.
이를 학습 성공이나 실제 통신문 정확도 개선이라고 보고하지 않는다.

## 1. 확인한 원인과 제외한 가설

### 내용 구별보다 기본 편향과 형식 변화에 더 크게 반응한다

- 기존 구간 후보는 균형을 맞춘 학습문항 진단 18건에서 7건만 정답이었다.
  예측은 오류 17, 근거 부족 1, 정상 0이다. 원래 학습자료의 작은 일부에 대한
  **추론 진단**이지 새 과적합 훈련이나 독립 성능 평가가 아니다.
- 이 18건의 평균 출력은 정상 25.0% / 오류 46.2% / 근거 부족 28.8%였다.
  학습자료 비율 25% / 50% / 25%에 가깝다. 모든 오류 판정에 자신감이 100%인 것이
  아니라, 비슷한 점수 중 기본적으로 높은 오류 점수를 계속 고르는 상태다.
- 같은 원문에서 정상↔관계 교환을 비교한 6그룹의 평균 확률 차이(L1)는 0.015였다.
  의미가 동일한 선택지 순서를 뒤집으면 같은 척도에서 0.131로 약 8.7배 크게 바뀌었다.
  12건 중 2건은 실제 라벨도 바뀌었다. R1도 12건 중 6건이 바뀌었다.
- 실제 학습 설정은 선택지 순서 섞기가 꺼져 있었다. 이는 위치 의존성에 대한
  취약점이지만, 위치 편향 하나가 붕괴의 전부라고 단정하지는 않는다.
- 세 분류의 내용 판별과 원문 확보 여부를 같은 모델에 맡겨 왔다. 규칙으로 확인할
  수 있는 근거 부족을 분리하는 것은 타당하지만, 두 선택지만 남기는 것으로
  기존 가중치가 갑자기 내용 대조를 배우지는 않았다.

위 측정은 **내용 구별이 충분히 학습되지 않았고 빈도/형식 편향이 남았다**는 근거다.
encoder 동결, 판단부 표현, 정답자료 다양성 중 어느 것이 주원인인지 분리하는 데는
새로운 통제 학습이 필요하다. 이번에는 예산을 넘겨 그런 실험을 하지 않았다.

### 실제 실행에서 확인해 제외한 것

- JSON 파일의 키/선택지 순서가 달라 보이는 현상은 있었지만, 실제 고정 러너는
  학습·평가 모두 `queue()`로 순서를 복원했다. 216문항의 토큰 IDs와 선택지 위치가
  모두 일치했다. **초기 파일 검사만으로 의심한 입력 순서 불일치는 실행상 원인이 아니다.**
- 저장 실패나 optimizer 미작동을 새 원인으로 돌리지 않았다. 기존 72 updates의
  저장/재로딩·head 변경·encoder 불변 영수증은 보존하고, 이번 진단에서는 두 모델의
  가중치와 파일 해시가 바뀌지 않았음을 확인했다.
- 기존 러너에는 다른 질문이 들어와도 설치된 질문으로 조용히 바꾸던 부분이 있어,
  앞으로는 의미가 다른 계약이면 거절하도록 보강했다. 이를 과거 붕괴의 확인된
  원인이라고 주장하지 않는다. 기존 pinned 실행본은 덮어쓰지 않았다.

## 2. 근거 부족과 의미 판별을 분리한 구조

1. 실제 원문 확보 기록에서 파일 무결성/페이지, 필요한 구역, 헤더·각주·병합,
   파일 역할과 버전 연결을 확인한다. 확보 목록에 있어도 필요한 구역이 실제 모델
   입력에서 빠졌다면 근거 부족으로 보낸다.
2. 없거나 모르는 근거가 있으면 규칙이 검수 대상으로 보낸다. 이진 모델은 호출하지 않는다.
3. 근거가 있는 구간만 실제 두 선택지로 추론한다. 세 분류 확률에서 근거 부족을
   지우고 재정규화하는 흉내가 아니다.
4. 선택지 순서 영향을 줄이는 연구 모드는 두 순서를 실제로 추론하고 확률을 동일하게
   평균한다. 임계값이나 가중치를 개발 정답에 맞추지 않았다. 정확한 동률은 보류한다.
5. 직접 확인된 내용 불일치는 모델의 정상 판정으로 덮어쓰지 않는다. 원문 근거,
   직접 검사, 모델 원판정, 최종 판정을 별도 필드로 유지한다.

새 `assess_source_evidence()`는 원문 확보를 검사한다. 원문은 충분한데 HTML 내용이
빠진 경우를 원문 확보 실패와 섞지 않는다. 기존 운영용 v2 `assess_evidence()` 동작은
그대로 유지했다. 원문의 `source_complete=true` 플래그 하나만으로 통과하지 않는다.

이 구조는 연구용이며 자동승인·공개·운영 모델 승격을 허용하지 않는다.
실자료의 페이지/헤더 확보 기록을 관측하지 못했으면 이를 임의로 만들어 적용하지 않는다.

- dev: 원래 72건 중 근거 부족 18건을 규칙으로 제외, 정상 18 / 오류 36 = 54건.
