## 2. 가중치를 고정한 입력 표현 비교

기존 노출 합성 **dev54문항(정상18/오류36)**을 사용했다. 신규 블라인드·실물 성적이 아니다.

실제 DOM 순서는 따로 기록했다. HTML에 없는 내용을 원문으로 자동 보충하지 않았다.
case_id·family·변형 연산·정답은 모델의 구간 본문에 넣지 않았다. 정답은 미니에서만 집계했다.

여러 참조를 한 구간에 표시하는 일반화된 표시 방식은 아직 운영 검증 대상이 아니다.
