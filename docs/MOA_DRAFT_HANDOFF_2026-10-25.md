# 저장된 개인 입력을 정식 수정본에 반영 — 15단계, 2026-10-25

## 담당자 사용 흐름

개인 임시 입력을 확인하고 해당 저장본의 항목·사유를 정식 검수 기록에 추가한다.
정식 수정본에서 자신이 사용한 개인 저장본을 다시 확인할 수 있다.

1. 임시 입력 비교·복구·읽기 전용 화면에서 **저장된 입력 정식 저장 전 확인**을 연다.
2. 현재 검수본, 저장된 구역/관계, 정식 기록에 포함할 사유를 확인한다.
   과거 입력을 가져온 저장본이면 원래 개인 입력으로 가는 링크도 유지한다.
3. 항목과 사유가 학교의 정식 기록에 추가된다는 확인란을 직접 선택하고
   **이 저장본으로 정식 수정본 저장**을 누른다.
4. 추가된 정식 수정본과 해당 버전의 HTML·다운로드로 이동한다.
   정식 검수 화면·이력에서 **내가 정식 저장한 임시 입력 확인**으로 돌아올 수 있다.

명시적으로 선택한 저장본 한 항목만 사용한다. 다른 탭에서 작성 중인 미저장 내용은 포함하지 않는다.
저장 후 상태는 `draft`이며 별도 담당자 확인이 필요하다. 공개 승인을 수행하지 않는다.
정식 사유는 기존 검수 계약대로 양끝 공백을 제거하지만, 개인 저장본의 원문은 그대로 보존한다.
JavaScript 없이도 확인·정식 저장·출처 조회가 가능하다.

이전 직접 검수 저장 흐름은 유지한다. 기존 정식 이력에 개인 출처를 추정해 붙이지 않는다.
최신 개인 저장본이며 동일 수신본·변환본·정식 검수 기준에 속한 완성된 입력만 반영한다.
빈 사유, 빈 구역 본문, 미완성/잘못된 관계, 변경 없는 입력은 반영하지 않는다.
기준이 바뀐 입력은 자동 병합하거나 현재 문서에 재해석하지 않는다.

## DB·권한·충돌 계약

| 경로 | 계약 |
|---|---|
| `GET /structure-draft/submit?id=…` | 하나의 SQLite 읽기 시점에서 저장본·최신 입력·검수 기준·반영 가능 여부 확인 |
| `POST /structure-draft/submit` | 인증·CSRF·Origin·명시적 확인 후 정식 수정본 1개와 개인 출처 연결 1개를 함께 저장 |

- 학교 schema **v6**은 `school_review_draft_handoffs(review_id, draft_id)`만 추가한다.
  두 ID는 각 이력에 대한 FK이며 각각 유일하다. UPDATE/DELETE 금지 trigger로 출처를 보존한다.
  INSERT trigger는 같은 학교·작성자·수신/변환·기준·직전 검수·동작 종류와 미확인 상태를 요구한다.
- `review.save`의 기존 `BEGIN IMMEDIATE` 안에서 소속·쓰기 권한·최신 저장본·검수 기준을 재검사한다.
  서버에 저장된 동작과 사유가 실제 정식 저장 내용과 일치해야 한다.
  정식 이벤트와 출처 INSERT는 하나의 트랜잭션이며 어느 하나 실패하면 함께 rollback한다.
- 같은 POST의 재전송, 두 탭의 동시 반영, 미리보기 뒤 자동저장/정식 검수 변경은 409로 중단한다.
  요청에는 텍스트·관계·사유를 받지 않으며 서버의 불변 payload만 사용한다.
  정확한 필드·확인값만 허용하고 중복/추가 필드·잘못된 UTF-8·4,096바이트 초과 POST를 거부한다.
  GET query도 기존 엄격한 검사와 4,096자 제한을 유지한다.
- 같은 학교라도 다른 담당자·manager는 개인 출처를 볼 수 없다. 다른 학교 자료는 404이다.
  reader는 본인 미리보기만 가능하며 정식 저장은 불가하다.
  개인 저장본 ID/출처 연결은 공유 검수 JSON·HTML 다운로드·ZIP에 포함하지 않는다.
  사용자가 확인한 **정식 항목과 사유**는 기존 학교 검수 권한에 따라 공유된다.
- v5→v6는 명시적 마이그레이션에서 SQLite backup 후 추가형 변경을 적용한다.
  신규 DB·이전 버전·반복 실행·알 수 없는 버전 거부, 기존 행·원본·core `user_version` 보존을 검증한다.
  서버 시작·조회·저장에서는 마이그레이션하지 않는다. v6 미적용 시 새 반영만 차단한다.
  기존 일반 정식 검수 저장은 v5에서도 계속 동작한다.
