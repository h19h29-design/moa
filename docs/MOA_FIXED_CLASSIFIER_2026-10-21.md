## 현재 결론

선택지 점수 방식 대신 **정상/오류를 고정 출력하는 분류기와 맥북 전용 실행 경로**를 구현했다.
맥북에서 작은 텐서 단위 검사2개와 실제 tokenizer 사전검사162문항을 통과했다.
그러나 **새 후보 학습·성능 평가·연구 체크포인트 저장은 아직 실행하지 않았다.**
기존 주간 후보 한도의 잔여가0이므로 한도를 우회하지 않고 `WAITING_BUDGET`으로 보존했다.
단위 테스트의 저장·재로딩은 작은 가짜 encoder를 이용한 코드 검사이며 LAYA 학습 성과가 아니다.

## 바꾼 것과 고정한 것

- 후보는 `moa-unattended-20261021-fixed-classifier-01` 하나다. 이전 이진 후보의 재개가 아니다.
- 입력은 기존 원문/실제 DOM의6개 필드와 같은 한국어 질문을 유지한다.
  선택지 문구·순서·MASK 위치를 없애며, 정답·case_id·변형 연산을 tokenizer에 넣지 않는다.
- 기존 R1의 encoder,2층 Transformer 판단부, 유형 embedding과 scorer MLP 앞부분을 재사용한다.
  선택지 위치별1점 출력 대신 CLS 대표 벡터를 정상0/오류1의 두 고정 출력으로 연결한다.
  새 마지막 출력층만 같은 seed로 초기화한다. 분류 방식 변경에 필요한 pooling/출력/입력 헤더 변경을
  묶어서 비교하는 실험이지, 이 구성 요소 각각의 효과를 이미 분리해 확인한 것은 아니다.
- encoder 동결, 원래 R1 초기 가중치, train108(정상36/오류72), dev54(정상18/오류36),
  seed20261020,4epochs, microbatch1/누적8, LR0.001→0.000001, weight decay0.01을 고정했다.
  새 클래스 가중치·재표집·임계값 탐색·epoch 추가는 없다.
- 두 클래스 정답의 기존 one-hot soft CE와 동등한 unweighted cross entropy를 사용한다.
  선택지 셔플/확률 평균 대신 고정 출력 한 번으로 각 문항을 판정한다.
- 근거 부족은 기존 원본 취득·필수 문맥·헤더·각주·역할 inventory 검사에서 제외한다.
  `source_complete=true` 문자열만 믿거나 이 규칙의 성공을 모델 성적에 합산하지 않는다.
- 기존 독립 합성 사실/변형 연산을 재실행하고 취득 원문·실제 DOM·파일 해시·그룹 분리를 재검사했다.
  새 원문 그룹을 확보했다고 하지 않는다. 기존 train/dev의 고정 비교이며 노출된 dev는 블라인드가 아니다.
  기존 blind와 실제 통신문·파생 평가자료는 열거나 학습으로 옮기지 않았다.
