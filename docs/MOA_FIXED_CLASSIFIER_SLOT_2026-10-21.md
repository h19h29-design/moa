# MOA 고정 분류기 — 후보 1개 예외 실행 현황

> 최신 추가 재개: 10월22일 승인된 두 게이트웨이 중지 후 같은 저장 후보를 한 번 재개했으나,
> 8/56updates에서 메모리 보호로 중단됐다. 두 게이트웨이는 복구 확인했고 새 성적은 없다.
> 아래 최초0-update 중단 기록은 보존한다. [추가 재개 결과](MOA_FIXED_CLASSIFIER_RESUME_2026-10-22.md)를 참조한다.

## 현재 상태

2026-10-21 사용자의 명시 요청에 따라 **정상·오류 전용 분류기 후보 1개에만 후보 수 예외를 등록**했다.
기존 시간 예산, 메모리 보호, 원장과 준비 PLAN/맥북 JOB/학습 설정은 바꾸지 않았다.
2026-10-22 08:00(KST)에 허용된 맥북 후보를 한 번 발행했으나, **실행 중 메모리 보호로 중단**됐다.
현재 `RECONCILIATION_REQUIRED`이며 **0updates/학습 미완료/평가 미실행**이다.
새 정상·오류 분류기의 정확도나 정상 오탐률은 측정하지 못했다.

최초 대기 관측인 10월21일21:10(KST)의 가용 메모리는 **6.65GiB**, 적재 전7GiB보다 약0.35GiB 부족했다.
AC·15분 유휴·메모리 압력·디스크는 충족했고 device.lock/다른 학습은 비사용 상태였다.
맥북 Codex 앱은 종료된 상태이며, 상위 사용량에는 기존 OpenClaw 서비스가 있었다.
당시에는 다른 작업을 보호하기 위해 서비스·프로세스·전역 캐시를 종료하거나 정리하지 않았다.

## 10월22일 승인된 메모리 확보와 실제 중단

- 사용자가 명시 허용한 맥북 OpenClaw 게이트웨이 **1개만** 잠시 정상 중지했다.
  다른 OpenClaw 게이트웨이와 MOA/OpenCode/Paperclip·DB·macOS 서비스는 중지하지 않았다.
- 기존 제어기와 잠금으로 적재 전7GiB·AC·유휴·메모리 압력·디스크 검사를 통과한 뒤
  같은 RUN을 맥북 MPS에 **한 번만** 발행했다. 후보/시간 추가나 PLAN/정책 변경은 없다.
- 실제 실행시간 **9.704770초**, optimizer 업데이트 **0/56회**다.
  최저 가용 메모리는 **5,329,321,984bytes(4.963318GiB)**로,
  실행 중5GiB 보호 기준보다 **37.5625MiB 부족**했다.
- `resource_or_reservation_day_guard` 안전 중단을 기록하고 0-update 판단부/학습 상태를 보존했다.
  이는 완료된 학습 모델이 아니다. 새 안전 중단 후 재발행하거나 저장 상태를 임의 재개하지 않았다.
- 학습용1800초 예약과 소비된 후보1개는 원장에 그대로 보존했다.
  실제 경과9.704770초와 예약1800초를 구분하며 임의 환급/초기화하지 않았다. 평가600초는 발행하지 않았다.
- 중단 직후 승인 게이트웨이를 **동일 LaunchAgent 설정으로 복구**했다.
  설정 해시 불변, 실행 중 상태, 기존 loopback 포트와 HTTP200을 확인했다.
  다른 OpenClaw 게이트웨이의 기존 프로세스는 유지됐다.
- 기존 R1 모델과 운영 registry/manifest 해시 불변을 확인했다.
  원문·DB·운영 모델·인증·보안/절전 설정·유료 API를 변경하거나 호출하지 않았다.
- `moa-r2`는 **PAUSED**로 전환했다. 추가 자원 정리나 재개는 별도 명시 허가 없이 하지 않는다.

## 이번 변경의 범위

- 대상은 `moa-unattended-20261021-fixed-classifier-01` 하나다. 완료한 이진 선택지 후보의 재학습이 아니다.
- 준비 시 봉인한 기존 구현·PLAN·JOB을 그대로 유지하고 별도 단일 후보 예외 제어기를 추가했다.
- 과거10개 후보와 이미 사용된 예외를 보존한다. 표준8개 정책은 수정하지 않았다.
  이번 RUN의 발행 시에만 과거 사용분에1개를 더한 유효 후보 한도를 사용한다.
  다른 후보·새 RUN·이전 후보의 시간 연장에는 이 권한을 사용할 수 없다.
- 자원 대기 중에는 추가 후보 권한을 소진하거나 학습시간을 예약하지 않는다.
  학습 발행 전 전체1800초를 기존 일일·주간 한도 안에서 예약한다.
  영구 소비 표시를 원격 발행 전에 기록하며, 불명확한 발행·새 안전 중단을 임의 재시도하지 않는다.
- 맥미니는 제어·자료 준비·정답 집계만 한다. 실제 모델 학습·추론·별도 재로딩 평가는 맥북 MPS 전용이다.
- 학습은 합성 train108,4epochs/예정56updates,최대120updates/1800초다.
  별도 평가600초, 주간8시간/하루3시간, 적재 전7GiB/훈련 중5GiB,
  AC/15분 유휴/메모리 압력/디스크/device.lock 보호를 유지한다.
- 근거 부족 규칙의 성공을 모델 성적에 합산하지 않는다.
  기존 blind·실제 통신문 평가자료를 학습에 넣거나 새 블라인드로 부르지 않는다.

## 자동 진행

최초에는 기존 `moa-r2`가 **이 고정 분류기1개만** 15분 간격으로 관찰했다.
현재는 실제 안전 중단으로 `RECONCILIATION_REQUIRED`이며 자동 확인을 **PAUSED**로 전환했다.
아래 명령은 기존 상태 확인 경로이지 재학습 허가가 아니다. 발행 표시·원장·체크포인트를 초기화하지 않는다.
예정했던 저장 모델의 별도 맥북 재로딩 평가는 학습 미완료로 실행하지 않았다.

**기존 전체 연구 캠페인의 PAUSED 표시는 유지한다.** 이전 후보를 실행하는
`research_cli advance`나 미니 학습 경로를 재활성화하지 않는다.
사용자가 맥북에 프롬프트나 파일을 전달할 필요가 없다.

```bash
/Users/mac-mini/.local/bin/dev-storage run Relocated-20261017/work/moa-push -- .venv312/bin/python -m moa.research_classifier_slot advance
```

위 명령은 기존 권한을 확인할 뿐 새 권한을 만들지 않는다. `grant`를 다시 호출하지 않는다.
영수증은 기존 비공개 SSD 캐시 `unattended-20261020/fixed-classifier/`에 보존한다.
