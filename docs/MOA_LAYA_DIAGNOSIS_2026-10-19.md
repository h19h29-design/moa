# MOA LAYA 오류 미검출 원인과 수정 결과 — 2026-10-19

## 쉽게 요약

모델 파일은 실제로 학습·저장됐지만, **내용의 차이를 판별하는 작업은 충분히 배우지 못했다.**
새 문서에서만 실패한 것이 아니다. 기존 학습용 240문항을 다시 풀려도 R1과 R2 모두 111개만 맞혔다.
대부분을 정상으로 답하기 때문에 정상 오탐은 낮지만 중요한 오류를 놓친다.

이번에는 무료 로컬 추론으로 원인을 확인하고, 학습자료의 질문 편향과 직접 검사기의 정상 재배치 오탐을 수정했다.
추가 훈련·운영 모델 교체는 하지 않았다. **LAYA 자체의 정확도 개선이나 실물 통신문 98% 달성은 아직 확인되지 않았다.**

## 1. 실제로 확인한 원인

### 학습한 문제 자체를 잘 풀지 못함

기존 합성 TRAIN 전체 240문항을 저장된 R1/R2로 각각 실제 재추론했다. 재학습은 아니다.

| 학습자료 재진단 | R1 | R2-A |
|---|---:|---:|
| 전체 정답 | 111/240, 46.25% | 111/240, 46.25% |
| 정상 판정 | 96/96 | 96/96 |
| 실제 오류 검출 | 15/96, 15.625% | 15/96, 15.625% |
| 오류를 정상으로 잘못 통과 | 81/96 | 81/96 |
| 근거 부족 검출 | 0/48 | 0/48 |
| 정상 오탐: 정상을 오류로 판정 | 0/96 | 0/96 |

두 모델 모두 240개 중 225개를 정상으로 답했다. 전부 다수 범주로 답하는 기준선은 40%다.
R2의 평균 음의 로그우도는 R1의 1.1721에서 1.0442로 낮아졌지만, 최종 선택과 오류 검출은 개선되지 않았다.
파일 저장·확률 변화·손실 감소만으로 “학습 성공”을 선언할 수 없는 상태다.
위 점수는 학습자료 재진단이며 독립 평가나 실물 정확도가 아니다.

### 질문만 보고 답을 추측할 수 있는 자료 편향

기존 TRAIN의 `omission` 질문 24개는 모두 오류였다. 같은 질문의 정상·근거 부족 대조군이 없었다.
따라서 실제 내용 차이 대신 질문 종류에 의존할 수 있는 지름길이 있었다.
기존 자료만으로 질문 종류별 다수 답을 고르면 50%가 나오는 구조였다.
이는 확인된 데이터 결함이지만, 낮은 성능의 유일한 원인이라고 단정하지 않는다.

### 실제 표 구조에 비해 너무 단순한 학습 범위

기존 학습 표의 데이터 행은 최대 2개였고, 좌우 반복 6열 표를 단일 3열 목록으로 재배치하는 입력이 없었다.
학과–교실 17개 연결, 정상적인 재배치와 관계 교환을 구분하는 능력이 입증되지 않았다.
새 회귀 자료는 이 부족을 드러내기 위한 시험용이며, 학습자료에 섞지 않았다.

### 입력·저장 오류 가설도 실제로 점검

- 기존 학습자료 24개와 선택지 순열 6종의 실제 tokenizer 텐서 및 정답 인덱스 144건이 학습·검사 경로에서 일치했다.
- 수정한 train/dev 320개도 맥북에서 실제 tokenizer 텐서·정답 인덱스 1,920건이 일치했다.
- 짧은 날짜 변경 문제는 잘리지 않았는데도 정상으로 답했다. 입력 길이만으로 설명되지 않는다.
- R1/R2 파일 SHA는 다르고 예측 확률도 달라, 같은 체크포인트를 잘못 불러온 상황은 아니다.
- 정상/날짜 변경의 encoder 표현도 달랐다. 입력의 날짜가 완전히 사라졌다고 볼 증거는 없다.
- 동결 encoder, 학습률, 업데이트 수, 판별부 용량 중 어느 것이 얼마만큼 원인인지는 대조 실험 전 미확정이다.

## 2. 실제 수정한 것

### 원문 관계를 보존한 정상 재배치 비교

`moa/scoped_verification.py`에 별도 버전의 시험용 검사기를 추가했다.
고정된 이전 평가의 `moa/verification.py`와 과거 블라인드 점수는 바꾸지 않았다.

명시적인 `연번/학과/교실` 좌우 반복 구조와 한 개의 대응 구간이 확인될 때만 6열→3열을 의미상 비교한다.
행 순서가 바뀌어도 연번·학과·교실 연결, 개수, 날짜·시간·금액·선택 수, 헤더·단위·각주·조건을 확인한다.
교실 교환·행 누락·중복 연번·각주 삭제는 통과시키지 않는다.
불명확한 병합 관계, 불완전한 원문 근거, 임의의 6열 표는 정상 재배치로 간주하지 않는다.
모바일 렌더러의 답이나 LAYA 판정을 이 검사기의 정답으로 복사하지 않는다.

### 질문 편향 제거와 준비 상태 점검

`moa/laya_diagnostics.py`에서 독립 합성 정답·원문/양식 그룹·train/dev 분할을 보존한 채 해당 예제의 질문 배정을 바로잡았다.
누락 여부에 답할 수 있는 정상·각주·조건 사례를 누락 질문의 대조군으로 연결했다.
정답, 실제 내용, 파일 역할, 원문 그룹을 바꾸거나 평가자료를 가져와 채우지 않았다.

| 수정 후 TRAIN | 정상 | 오류 | 근거 부족 |
|---|---:|---:|---:|
| 조건 | 48 | 48 | 24 |
| 누락 | 24 | 24 | 12 |
| 표 관계 | 24 | 24 | 12 |

train 240 / dev 80개를 맥북의 격리된 수신 폴더로 전달했고 파일 해시와 1,920건 입력 검사를 확인했다.
학습 작업은 발행하지 않았다. 상태는 **질문 대조군 준비 완료, 훈련 READY 아님**이다.
실제 긴 표 학습 범위의 부족은 별도로 남아 있다.

추가 점검은 혼합 분할로 정상 대조군 부족을 숨기는 입력, 공유 질문 정의 변경, 질문 수정 후 중복 입력, 원문/양식 분할 누출을 거부한다.
학습자료의 세 범주별 재진단도 구분해, 체크포인트 존재만으로 다음 평가를 시작하지 않게 하는 진단 도구를 추가했다.
이는 새 진단 도구의 기준이며 기존 운영 워커의 READY나 자동승인 정책을 바꾼 것이 아니다.

## 3. 새 정상 재배치 회귀 시험

독립적으로 작성한 합성 원문/결과 100문항을 사용했다. 한 가지 배치 양식의 10개 변형이며 실제 문서 100건이 아니다.
정상 재배치 20개, 내용 오류 70개, 근거 부족 10개다. 표 길이는 3·7·17행이다.
정답은 사전에 정한 변경 연산에서 만들었고, 검사기나 LAYA의 답을 정답으로 쓰지 않았다.

| 같은 100문항 | 기존 직접 검사 | 수정 직접 검사 | 저장된 R2 단독 | 직접 검사 우선 결합 |
|---|---:|---:|---:|---:|
| 전체 정답 | 80/100 | 100/100 | 20/100 | 100/100 |
| 정상 오탐 | 20/20 | 0/20 | 0/20 | 0/20 |
| 오류 검출 | 70/70 | 70/70 | 0/70 | 70/70 |
| 근거 부족 정답 | 10/10 | 10/10 | 0/10 | 10/10 |
| 길이 초과 미완료 | 0 | 0 | 4 | 0 |

날짜·시간·금액·선택 수·교실 교환·행 삭제·각주 삭제 각각 오류 10/10을 직접 검사기가 검출했다.
R2의 오류 70개 중 66개는 정상 오판, 4개는 길이 초과로 미완료다. 잘라서 통과시키지 않았다.
결합 성적의 향상은 직접 검사기 덕분이며 LAYA가 추가로 검출한 오류는 0개다.

**이 100%는 수정한 범위의 회귀 시험 결과다. 새 블라인드나 HWP/PDF 원문 전체 정확도가 아니다.**
재배치 전 추출이 틀렸거나 원문에 없는 내용은 이 시험만으로 보증하지 못한다.
최종 코드 검토 후 같은 회귀 입력을 재검산했고, 모델 원응답은 재실행·교체하지 않고 원래 영수증과 분리 보존했다.
