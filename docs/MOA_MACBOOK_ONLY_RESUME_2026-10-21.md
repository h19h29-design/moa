## 현재 실행 원칙

사용자의 최신 지시에 따라 맥미니는 자료·예산 검증, 작업 발행과 결과 회수만 담당한다.
실제 LAYA 학습과 저장 모델 재로딩·추론은 기존 MacBook Air M1의 격리 MPS 환경에서만 한다.
이 문서는 이전 `MOA_BINARY_RESUME_2026-10-21.md`의 맥미니 CPU 실행 방침을 대체한다.
과거 기록 자체는 수정·삭제하지 않는다.

대상은 `moa-unattended-20261021-binary-train-01` 하나다.
새 후보·추가 예산·새 재개 허가를 만들지 않는다. 기존 미소진 재개 1회만 사용한다.
원래 예약 시각은 2026-10-21 07:52:19 KST이며 그 날짜를 넘겨 훈련을 발행하지 않는다.

## 보존과 안전

- 기존 PLAN·허가·예산 원장·실패 결과·모델·optimizer 경계를 원본 그대로 보존한다.
- 기존 승인에 연결된 결과 원본 해시와 optimizer 해시를 전송 시점 및 매 실행 전에 대조한다.
  다른 유효한 0-update 경계가 있어도 이번 승인으로 대신 사용하지 않는다.
- 별도 장치 이전 overlay와 이전 JOB의 해시를 참조하는 실행 리비전을 사용한다.
  변경은 CPU→맥북 MPS의 실행 위치뿐이다. 데이터·질문·라벨·학습 설정은 같다.
- 기존 원장은 바이트 단위 불변이며 이전 누적 5.913초를 이어간다.
- 합성 train108/dev54, 두 선택지, 기존 R1 초기 가중치, seed·4 epochs·encoder 동결·학습률을 유지한다.
  예정56 updates, 최대120 updates/누적1800초, 별도 평가 누적600초다.
- 맥북 적재 전 가용7GiB, 실행 중5GiB, AC·사용자 유휴900초·메모리 압력·디스크·장치 잠금을 검사한다.
  다른 앱·서비스·사용자 작업·전역 캐시를 종료하거나 보호 기준을 낮추지 않는다.
- 안전 조건이 부족하면 재개 허가를 소비하지 않고 대기한다.
  발행 영수증을 먼저 저장하며, 불명확한 전달·손상·재중단 뒤 두 번째 훈련을 하지 않는다.

기존 예약 안에서 실행 장치를 이전하는 것이므로, 이후 성능 차이는 장치 변경의 영향도 포함한다.
동일 장치의 학습률 단일 변수 비교라고 부르지 않는다.

## 연결과 자동 재확인

기존 인증된 `macbookair` SSH와 기존 LAYA 설치·장치 잠금을 재사용한다.
새 공개 포트·Tailscale·가상환경·모델 다운로드·유료 API는 사용하지 않는다.
원격 전송은 해당 후보의 고정 디렉터리와 해시 목록으로 제한하고, 기존 다른 파일은 덮어쓰지 않는다.

기존 `com.moa.research`와 `moa-r2`는 같은 컨트롤러 잠금을 사용한다.
장치 이전 PLAN이 있으면 맥북 경로로만 진행하고 맥미니 학습 실행 함수는 명시적으로 거부한다.
오프라인이면 대기하지만, 연결 성공 후 해시·안전 검사가 거부되면 단절로 숨기지 않고 중지한다.
COMPLETE 또는 RECONCILIATION_REQUIRED이면 heartbeat를 일시 중지한다.

```bash
/Users/mac-mini/.local/bin/dev-storage run Relocated-20261017/work/moa-push -- .venv312/bin/python -m moa.research_cli status
/Users/mac-mini/.local/bin/dev-storage run Relocated-20261017/work/moa-push -- .venv312/bin/python -m moa.research_cli pause
```

`resume`은 이미 검증·봉인한 연결의 조정자만 다시 활성화한다. 새 허가나 시간·후보를 주는 명령이 아니다.
실제 훈련이 이미 발행됐다면 위 `pause`는 이후 작업 발행을 막으며, 원격 실행 중인 훈련을 즉시 종료하는 명령은 아니다.

## 비교 결과의 범위

완료하면 맥북의 별도 프로세스에서 저장 모델을 재로딩하고, 기존 노출 합성 dev54를
사례별 정방향·역방향 선택지 순서로 평가한다. 정답은 맥미니에만 유지한다.
모델 원판정 정확도·정상 오탐·실제 오류 검출을 기존 R1/구간 후보/학습률 후보와 비교한다.
근거 부족 규칙의 성공은 모델 점수에 더하지 않는다. 새 블라인드·실제 통신문 성적이 아니다.

기존 참고 성적은 R1 정확도48.1%/정상 오탐16.7%, 구간 후보64.8%/94.4%,
학습률 후보66.7%/77.8%다. 새 이진 후보가 실제로 학습·평가되기 전에는 새 점수를 쓰지 않는다.

NAS 운영 DB·원문·수집기·인증·운영 모델·사람 승인·자동 공개 설정은 변경하지 않는다.

## 실제 검증 기록

- 수정 전 경계 대조 누락·불완전 계약·평가 순서·SSH 오류 구분 실패를 재현한 뒤 수정했다.
  관련 컨트롤러 테스트 **58 passed**. 전체 회귀 **1042 passed, 3 skipped, 31.68초**.
- 기본 환경에 없는 Torch 관련 3개 모듈은 기존 격리 환경에서 **11 passed, 1.60초**.
  작은 텐서/설정 단위 검증이며 실제 LAYA 후보 학습·추론은 수행하지 않았다.
- `compileall`, `git diff --check` 통과. 독립 검토에서 발견한 승인 경계 대조 문제를 보완하고 재검토했다.
- 맥북에 해시 검증된 파일13개를 전송했다. 기존 설치 코드·보호된 모델 메타데이터·R1 해시가 일치한다.
- **실제 맥북**에서 tokenizer·금지된 잘림·선택지/정답 index·optimizer 저장 상태를 검사했다.
  train108/dev54, 실제 순열324개, 최대804 tokens, skipped0/truncated0, MPS 사용 가능을 확인했다.
  optimizer 상태는 기존0-update 경계와 일치하며 모델 적재·추론·훈련은 하지 않았다.
- 맥북 전용 조정자로 실제 `advance`를 실행한 결과 **WAITING_BOOK_RESOURCE**.
  관측 가용6804684800 bytes(약6.34GiB), 시작 기준7GiB까지 약0.66GiB 부족하다.
  AC·유휴·메모리 압력은 통과했다. 값은 변동 가능하며 조건을 다시 확인한 후에만 발행한다.
- 기존 `com.moa.research` 로드를 유지하고 `moa-r2`의 지시문을 **맥북 전용**으로 갱신·활성화했다.
  맥미니 CPU 경로는 실행을 거부한다. 새로운 자동작업·별도 훈련을 만들지 않았다.
- 기존 PLAN·재개 허가·예산 원장 바이트 불변. 추가 재개 발행 영수증 없음, 권한 미소진이다.
  훈련0 updates/이전 누적5.913초 그대로이므로 **새 정확도·정상 오탐률은 미측정**이다.
- 사용자 프롬프트 전달은 필요 없다. 자원이 확보되면 같은 후보를 딱1회 재개하고,
  성공 시 별도 재로딩·기존 성적 비교를 이어간다. 재중단·당일 예약 만료는 추가 재개 없이 중지한다.
