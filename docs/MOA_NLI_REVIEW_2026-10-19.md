# MOA 실물 검수·한국어 로컬 NLI 시험 — 2026-10-19

## 결론

새 한국어 모델은 LAYA보다 오류를 많이 찾았지만 **직접 검사기에 추가한 오류 검출은 0건**이었다.
따라서 운영에는 연결하지 않았다. LAYA 재학습, 운영 모델 교체, 자동 승인·공개, 유료 API 호출은 모두 0이다.

실물 17건의 비교 화면과 원본 다운로드를 다시 확인했다. 사람 정답·승인은 아직 0건이므로
실제 통신문 정확도나 실제 검수 시간 절감률은 계산할 수 없다. 먼저 대표 5건을 사람이 확인해야 한다.

## 2. 비교 방법과 한계

원문과 **실제 DOM**의 같은 구역을 양방향으로 비교한다. 작은 날짜 변경이 긴 문장에 묻히지 않도록
독립 사실·표 행으로 나누되, 표 머리글·단위·각주·병합 관계와 순서 의존 문맥을 유지한다.
명시적으로 확인된 연번/학과/수업교실 반복 헤더 외의 6열 표를 임의로 정상화하지 않는다.
입력 초과·불분명한 대응·누락된 행/문맥은 완료로 처리하지 않는다. 원문 값을 DOM에 채워 넣지 않는다.
행 위치 참조는 각주뿐 아니라 제목·조건·필수 내용에서도 보존한다. 물리적 행을 참조하는 6열 표는
세로 목록의 행 번호로 임의 재해석하지 않고 대응 미확정으로 남긴다.

- 양방향 entailment: 해당 입력에서 의미 일치 후보.
- contradiction: 의미 충돌 경고. 모든 문서 오류를 검출했다는 뜻은 아니다.
- neutral: 의미 일치를 확정하지 못함. **원문 부족의 증명이 아니다.**
- 입력/대응 미완료: 모델 판정 없음. 규칙의 근거 부족 정답으로 모델 성적을 올리지 않는다.

직접 불일치나 근거 부족은 어떤 모델의 `preserved`도 덮어쓰지 못한다.
원본 전체 페이지, 해당 구역, 표 문맥, 파일 역할의 근거 확인은 기존 별도 가드가 맡는다.
파일 역할은 모델로 확정하지 않는다. 역할·페이지가 미확인이면 모델이 일치라고 해도 사람 검수가 필요하다.

개발 자료에서는 같은 가중치·같은 54문항의 전체 구역 입력을 사실 단위 입력으로 바꿨을 때
모델의 MOA 투영 정답이 14/54→31/54, 오류 검출이 2/30→19/30으로 변했다.
입력 방식 개선 효과이지 학습 효과가 아니다. 새 시험에서 임계값을 조정하지 않았다.

이를 보완해 별도 저작한 **4그룹·58문항**을 새로 비교했다. 자료는 기록관 관람·연구 지원·급식

## 5. 실물 17건과 최소 검수

HWP 14, HWPX 2, PDF 1을 기존 격리 평가 사본에서 재사용했다. 원본/HTML SHA가 유지되고
일관된 SQLite 백업을 새 시험 경로에 만들었다. 과거 31개 평가 메타데이터도 삭제하지 않았다.
파서 플래그상 완전 14/17, 미완전 3/17은 이전 범위와 같다. **사람이 확인한 정답률이 아니다.**

대표 5건·신규 12건의 총 27개 선택 구역에 새 로컬 NLI(v2 고정 입력)를 실제 실행했다.
16개는 양방향 일치, 7개는 neutral 포함 의미 미확정, 4개는 미완료(입력 초과 3·대응 불명확 1)였다.
전체 페이지·표 근거·역할 미확인 때문에 **17건 모두 사람 검수 필요**로 유지했다.
사람 내용 정답/승인 0, Codex가 대신 제출한 승인/보류 0이다.

맥미니에서 새 시험 화면:

- [대표 5건](http://127.0.0.1:18326/)
- [신규 12건](http://127.0.0.1:18327/)

1. 기존 검수 암호로 로그인한다. 검수자 이름은 입력하지 않는다.
2. 먼저 대표 5건에서 **원본·모바일 비교로 이동**을 누른다.
3. 원본과 날짜·시간·금액·신청 조건·선택 수·표 연결을 확인한다.
4. 안내문은 모바일 HTML, 작성용 신청서·동의서·참고자료는 원본 첨부인지 확인한다.
5. 확인한 버전만 큰 **승인** 버튼을 누른다. 미확인/의심되는 부분은 **보류**한다.
   제안된 보류 사유는 저장 전 변경할 수 있다. 보류는 오답 정답지가 아니다.

대표 5건의 공통 확인 사항은 원본 전체 페이지 확보, 반복 표의 항목 연결,
일정·신청 조건 누락 여부, 병합 헤더/각주/단위, 안내·서식 경계다.
HWP는 브라우저 원본 페이지 렌더링을 지원하지 않는다. 나란히 보이는 것은 **추출 텍스트**이며,
실제 HWP는 새 탭의 원본 다운로드로 전용 뷰어에서 확인해야 한다.
이미지/스캔 PDF OCR·복잡한 미확인 병합·누락 페이지·불명확한 역할은 자동 확정하지 않는다.
확인된 평가자료도 평가 전용으로 남으며 학습·사례 검색으로 자동 이동하지 않는다.

## 6. 공개 접속의 403은 어떻게 됐나

기본 HTTP 도구에서는 `/`·`/login`이 Cloudflare 403이었지만 일반 Chrome에서는
익명 `/` 401, `/login` 200이었다. **보안 해제나 User-Agent 위장은 하지 않았다.**
정상 브라우저에서 기존 암호 로그인 303→홈/검수 200, 원본·HTML·ZIP 다운로드 200을 확인했다.
익명 자료 다운로드는 401이다. 승인/보류/업로드/역할 변경은 제출하지 않았다.

기존 별도 Cloudflare 자격증명으로 API 인증·대상 DNS·Access 목록은 읽을 수 있었고
대상은 proxied CNAME, MOA에 대응하는 Access 앱은 발견되지 않았다.
보안 규칙 조회는 권한 부족 403이라 **어떤 규칙이 HTTP 도구를 차단했는지는 확정하지 못했다.**
전체 서비스 장애나 앱 암호 오류로 단정하지 않으며 Cloudflare/방화벽/로그인/TLS/공개 포트 설정은 변경하지 않았다.
공개 사이트는 운영 코드 그대로다. 위 새 검사 설명 UI가 공개 NAS에 배포됐다는 뜻은 아니다.

## 7. 검증·보호·남은 일

- 변경 전 전체 검사 484 passed / 2 skipped. UI 비교/제안·라벨/누락/긴 표 경계 실패를 실제 재현했다.
- 최종 검토에서 행 참조 문맥·부모 ID가 다른 원자 입력 중복을 추가로 RED 재현하고 수정했다.
  기존 132회귀의 실제 pair ID/텍스트/방향/coverage가 변경되지 않았음도 별도 확인했다.
- 최종 전체 검사 **509 passed / 2 skipped (30.27초)**. Python 컴파일·JS/설치 셸 구문·diff 검사 통과.
- Mini에 Torch가 없어 제외된 모듈의 관련 7개 CPU 검사를 맥북에서 별도 실행해 통과했다.
  이는 합성 tensor 단위 검사이며 LAYA 훈련이나 운영 모델 로딩이 아니다.
- 실물 17건: 인증 후 360/393/430px, 원본/HTML/ZIP SHA 검증. 1280/393px 비교·편집 가능한 사유·원본 새 탭·수정 메뉴 확인.
  익명 자료 7경로×2서비스 401, 앱 콘솔 오류 0, 실제 검수 POST 0.
- sidecar는 원본 역할 목록·HTML 리비전·모델 입력·체크포인트·검사 버전과 결합하며
  오래되거나 잘못된 설명은 현재 결과로 표시하지 않는다. 문자 차이 강조는 의미 오류 확정이 아니다.
- 새 DB schema/마이그레이션은 없다. 기존 스키마 5와 worker 계약을 변경하지 않았고 NAS collector/review 코드는 보존했다.
  맥북 R1/R2-A·원래 venv·완료 대장·원문·검수 기록도 유지했다. 시험 화면에만 변경을 적용했다.
- 맥미니가 SSH 발행·해시 확인·결과 회수·완료 상태를 관리했다. 사용자에게 맥북 프롬프트 전달을 요청하지 않았다.
  완료 요청을 다시 실행하거나 자동 학습하지 않는다. 기존 worker/tunnel/relay는 유지한다.
- Muse JSON 오류는 별도 미해결, JEV 무료 자격 미확인으로 호출하지 않았다. 유료 API·자동 충전도 없다.

새 모델은 **비권위 시험 결과로만 보관**한다. 다음 자동화는 직접 사실·관계 대조와 근거 확인,
새 유형/불일치/neutral/입력 초과를 우선 검수 큐로 모으는 범위까지다.
사람의 원문 정답·권한·원문/양식 그룹 계보가 확보되기 전에는 실물 자동 승인·공개·학습으로 확대하지 않는다.
다음 개선 대상은 LAYA 반복 학습이 아니라 독립 개발 자료로 검증하는 한국어 표현 동등성 처리와
실물 5건의 정답/오류 위치 확보다. 현재 시험 116문항도 이제 노출된 회귀자료로 취급한다.
새 58문항도 이번 결과 공개 후에는 회귀자료로만 사용하며 다음 임계값 보정 자료로 재사용하지 않는다.
