## 3. R2-B 실행 여부

**미실행: 진단 실패로 차단.** 요청의 “작은 자료에서도 개선되지 않으면 전체 훈련으로 넘어가지 않는다”를 적용했다. 남은45분/400회 한도를 채우려고 반복하거나 epoch를 늘리지 않았다.

조건부 실행 코드는 별도 journal·lease fencing·누계 예산·중간/최종 저장·재로딩으로 제한한다. 정상240문항/2epochs라면60updates이며400회를 채우지 않는다. 알 수 없는 종료·손상·미확인 상태를 자동 재시도하지 않는다.

운영 READY, 기존 모델 registry/manifest, R1/R2-A 파일, 옛 실행 대장은 보존했다.

## 7. 안전 장치와 자동 조율

맥미니가 자료 적격성·파일 해시·맥북 온라인·AC/15분 유휴/메모리·device.lock을 확인하고 고정 작업을 발행·추적·회수한다. 같은 run 중복 시작을 막으며 optimizer 경계와 누계 시간/updates가 검증될 때만 재개한다.

완료된 진단·평가와 후보 버전을 보관한다. 현재 대장은 진단 gate 실패이므로 `complete_no_new_training`이다. 다음 후보는 새로운 제한된 허가·정답자료·평가 기준 없이는 준비/시작하지 않는다. 이전 `moa-r2` heartbeat는 중지 상태를 유지한다.

검토 중 발견한 오류4개를 재현·수정했다.

1. 중간→재개→최종 모델의 reload 영수증 충돌: 체크포인트 전체 SHA별 불변 이력으로 분리.
2. 미확인 역할이 notice로 승격: unknown 보존, 명시적 역할 확인 기본값False.
3. 모델 충돌이 있어도 추가 검수0으로 집계: 최종 품질과 실제 검수 요청을 별도 집계.
4. 알 수 없는 controller 상태가 새 훈련으로 흐름: 수동 조정으로 차단.

이번 실제 맥북 실행본 `code-v1`과 그 해시는 별도 보존했다. 후속 코드 수정본을 과거 실행본으로 보고하지 않는다. 수정된 보호 코드는 회귀 검증했지만, 실제 자원 중단→재개 전체 MPS 실험은 새로 실행하지 않았다.
