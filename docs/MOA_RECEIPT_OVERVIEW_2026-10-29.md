# 내 다운로드 영수증 모아보기 — 23단계, 2026-10-29

## 담당자 흐름

저장한 확인 완료본 묶음 → **내 다운로드 영수증 모아보기**에서 여러 묶음에 남은 영수증을
함께 조회한다. 내 학교·내 계정의 기록만 표시하며 보관함의 기록도 기본으로 포함한다.
묶음 이름 일부, 영수증 기록일 시작/끝, 묶음의 현재 보관 상태를 함께 검색할 수 있다.

검색 결과에는 묶음 수·영수증 수·기록된 ZIP 바이트 합계와 각 영수증의 묶음 이름·회차·시각·
문서 수·ZIP 바이트·SHA-256을 표시한다. 반복 다운로드 기록도 각각 합산하며,
영수증이 없는 묶음은 검색 결과와 합계에서 제외한다. 영수증은 ZIP 전송 직전 기록으로 수신 완료 증명은 아니다.

**이 묶음의 영수증·CSV**를 누르면 선택한 묶음의 기존 영수증 화면으로 이동한다.
기간 조건은 유지하며 해당 묶음의 전체 검색 결과 CSV를 기존 규칙대로 내려받는다.
개별 영수증 화면에서 모아보기로 돌아올 때도 기간을 유지한다.
여러 묶음을 합친 CSV는 이번 범위에 포함하지 않는다.

원본·수신/변환 버전·검수 이력·저장한 고정 목록·보관/복원 이력·다운로드 영수증을 수정하지 않는다.
보관하거나 문서 검수가 다시 열려도 과거 영수증은 조회할 수 있고, 실제 문서 ZIP의 버전 변경 차단은 유지한다.

## HTTP·권한·검색 계약

`GET /confirmed-export/receipts`만 추가한다. POST 처리나 기록 갱신은 없다.

| 입력 | 계약 |
|---|---|
| `q` | 최대 120자, 묶음 이름의 문자 그대로 부분 검색. `%`, `_`, `\`는 와일드카드가 아니다. ASCII 대소문자를 구분하지 않는다. |
| `from`, `to` | 선택 입력. 한국 시간의 영수증 기록일 기준, 양 끝 날짜 포함. `YYYY-MM-DD` 실제 달력값·시작≤끝 검증. |
| `state` | `all`(기본), `active`, `archived`. 다운로드 당시가 아닌 묶음의 **현재** 보관 상태. |
| `page` | 1부터 1,000,000까지 정수. 페이지당 20건, 마지막 페이지 초과는 마지막 페이지로 제한. |

- 최신 기록 시각 → 묶음 ID → 영수증 회차 내림차순으로 정렬해 같은 시각에도 순서를 고정한다.
  페이지 이동은 이름·기간·상태를 유지하고, 검색 제출은 첫 페이지에서 시작한다.
- 합계·현재 보관 상태·페이지 행을 한 SQLite 읽기 스냅샷에서 계산한다.
  조회 도중 다른 연결에서 영수증 추가나 보관이 발생해도 한 응답의 합계와 행이 섞이지 않는다.
- 현재 소속을 확인하고 학교와 계정을 목록·영수증·보관 이벤트 조인 모두에 적용한다.
  타 학교·같은 학교의 다른 담당자 기록은 목록과 합계에 포함하지 않는다.
  reader로 바뀐 소유자는 자기 기존 영수증을 조회할 수 있다. 소속 해제·학교 비활성·미로그인은 차단한다.
- 허용된 단일 필드만 받으며 중복·알 수 없는 필드·잘못된 숫자/날짜·과도한 길이는 400으로 거절한다.
  학교/계정 선택값을 URL에서 받지 않는다. 조회 문자열은 최대 4,096자다.
- 이름·입력·링크를 escape하고 기존 `private, no-store`, `nosniff`, CSP를 유지한다.
  검색·페이지 이동·개별 CSV 연결은 JavaScript 없이도 동작한다.
