# 검수 입력 자동 임시저장 — 11단계, 2026-10-24

## 승인 범위·구현 결정

사용자가 요청한 입력 자동 임시저장과 저장 상태·실패 표시를 구현했다.
기존 개인 항목별 초안(v4)·인증·CSRF·현재 기준/초안 CAS를 재사용했다.
브라우저 저장소나 정식 검수에는 자동 기록하지 않는다.

- 수정 가능한 구역/관계 폼만 입력 후 1.5초에 저장하며 페이지 내 요청은 하나씩 처리한다.
  로드/복구만으로 저장하지 않으며 확인/확인 취소/과거 검수본 복원은 대상이 아니다.
- 대기/저장 중/완료/실패를 항목별 표시한다. 통신 오류는 현재 입력을 유지하고 명시적 재시도로 처리한다.
  응답 유실 재시도는 **동일 요청**을 먼저 확인하며 동일 기준/직전 초안/내용일 때만 기존 저장을 확인한다.
  권한·기준 변경·다른 탭 충돌은 자동 재기준화/덮어쓰기하지 않는다.
- 완료 응답이 확인된 입력만 이동 유실 경고에서 해제한다. 요청 중 새 입력은 계속 미저장 상태다.
  JavaScript가 꺼지면 기존 수동 임시저장/복구가 유지된다. localStorage/외부 전송/새 의존성은 없다.
- 원본·기존 검수·다운로드·저장 목록 위치와 DB 스키마는 변경하지 않는다.
  NAS 접속/운영 변경·모델/학습/유료 호출·배포는 하지 않는다.

## 담당자 사용법·실패 처리

1. 수정 가능한 구역·관계 항목을 입력하면 1.5초 후 개인 초안으로 저장한다.
   항목 아래 **대기 → 저장 중 → 임시저장 완료·시각** 표시를 확인한다.
2. 완료된 입력은 같은 계정의 **내 임시 저장 입력** 또는 항목의 복구 링크로 다시 연다.
   복구만으로 정식 검수·확인·HTML은 바뀌지 않는다. 정식 저장은 기존 버튼으로 한다.
3. 통신 실패 시 입력은 화면에 남고 자동 재시도는 멈춘다.
   **임시 저장 다시 시도**는 응답을 받지 못한 동일 요청부터 확인한 다음 새 입력을 저장한다.
   저장은 됐지만 응답만 사라진 경우 같은 스냅샷을 중복 추가하지 않는다.
4. 다른 탭의 초안·정식 검수·기준 변경은 충돌로 표시하고 자동저장을 중지한다.
   권한/로그인·입력 검증 실패도 무한 재시도하지 않는다. 새 화면에서 저장본과 대조해야 한다.
   현재 화면의 미저장 내용을 보존한 뒤 이동하며 자동 덮어쓰기·병합은 없다.

- 요청 중 추가로 쓴 글은 완료 처리하지 않는다. 확인된 요청의 입력만 유실 경고에서 해제한다.
- IME 조합 중에는 새 요청을 시작하지 않는다. 페이지 전체 자동저장 요청은 하나씩 실행한다.
- 정상 응답 확인 전 화면을 닫거나 세션이 끝나면 아직 저장되지 않은 글은 유실될 수 있다.
  브라우저 영구 저장소·오프라인 저장·종료 시 강제 전송을 추가하지 않았다.
- JavaScript가 없거나 지원되지 않으면 기존 항목별 수동 임시저장을 사용한다.
  확인 체크·확인 취소·과거 검수본 복원은 자동저장 대상이 아니다.

## 서버·DB·보안 계약

- 신규 `POST /structure-draft/autosave`는 기존 단일 항목 폼 검증과 v4 개인 초안 저장을 사용한다.
  성공 응답은 `id`, `created_at`, `resume`만 포함하며 본문·사유·인증값을 반환하지 않는다.
  응답과 페이지의 `no-store`, 기존 CSP·HTML escape·SQL 바인딩·CSRF·Origin 검사를 유지한다.
- 기존 `BEGIN IMMEDIATE` 안에서 소속/수정 권한, 수정 가능한 최신 수신·변환,
  구조 hash·정식 검수·항목별 초안 ID를 모두 대조한다.
  동일 내용의 응답 확인도 현재 기준과 같은 최신 초안 또는 바로 직전 요청인 경우만 허용한다.
  이전 스냅샷을 UPDATE/DELETE하거나 다른 담당자·학교의 개인 입력을 읽지 않는다.
- 수동 저장은 여전히 명시적 불변 스냅샷 추가다. 자동저장의 동일 요청 확인과 구분한다.
  DB 스키마 추가·마이그레이션 변경은 없다. v4 미설치 시 조회/저장으로 자동 마이그레이션하지 않는다.
- 기존 필드 길이·중복·UTF-8·NUL 검증과 POST 300,000 bytes 제한을 적용한다.
  자동저장만 세션당 60초에 120회로 제한하고 429를 반환한다. 대기열 자동 재시도는 없다.
  클라이언트 요청은 10초에 취소하며 응답 유실로 취급한다.
- 원본·변환 결과·기존 검수·이전 다운로드·저장 연속 목록의 위치는 자동저장으로 변경하지 않는다.
  외부 전송·모델 호출·새 의존성·백그라운드 자동 작업을 추가하지 않았다.
