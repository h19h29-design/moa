# 학교 문서 구조 변경점 비교 — 5단계, 2026-10-23

## 사용 흐름과 범위

학교 전용 로그인 → 수신본 → 담당자 구조 검수 → **자동 분석본과 변경점 비교**.
검수 이력의 **직전 검수 버전과 비교**나 수정본 HTML 미리보기에서도 접근한다.

- 같은 수신본·변환 버전 안에서 **자동 분석 원본 / 특정 검수 시점 / 이전 검수 시점**을 선택한다.
  두 시점은 URL에 고정된다. 비교 기준과 대상을 바꾸거나 같은 버전을 선택할 수 있다.
- 변경된 구역의 텍스트·종류를 나란히 표시하고, 헤더·본문·각주·여러 첨부의 파일명과 원본 위치를 보존한다.
  모바일에서는 기준/대상을 위아래로 표시한다.
- 기준의 변경 범위는 취소선, 대상의 변경 범위는 밑줄로 구분한다. 공통 앞·뒤를 제외한 **중간 전체 범위**이며,
  중간에 같은 단어가 포함될 수 있다. 최소 단어 단위 편집 거리나 의미 동일성 판정은 아니다.
  공백·줄바꿈·Unicode를 정규화하여 실제 차이를 숨기지 않는다.
- 관계는 `종류 + 출발 + 대상` 묶음별로 추가·제거·근거 변경을 표시한다.
  같은 관계의 복수 자동 근거를 모두 보존하고, 자동 후보와 담당자 지정 근거를 구분한다.
- 확인 완료·확인 취소 등 **검수 상태 변화는 내용 변경 수에 합산하지 않는다**.
  변경이 없다는 것은 완전성·정확성 보증이나 공개·학습·운영 승인이 아니다.
- 기존 파일 역할, 분석되지 않은 첨부, 완전성 상태와 원래 경고를 계속 보여준다.

새 수신 정정본이나 재변환 사이의 자동 대응은 하지 않는다. 서로 다른 변환의 block ID가 같은 내용을
가리킨다는 보장이 없으므로 그런 조합은 거부한다. 표 셀·파일 역할·원본 위치는 기존 검수 편집 대상이 아니며,
이 기능에서도 편집·재구성하지 않는다. 이번 단계는 공개·전송·배포 기능이 아니다.

## 조회·DB 계약

새 테이블·마이그레이션이 없다. 기존 학교 schema v2, 저장된 자동 분석과 append-only 검수 overlay를 읽는다.

| 항목 | 계약 |
|---|---|
| 경로 | `/structure-compare` (학교 전용 인증 서버만) |
| 필수 pin | `id`, `revision`, `left`, `right`; `left/right=original`은 자동 분석 원본 |
| 형식 | 기본 HTML, `format=json`은 현재 페이지의 비교 데이터 |
| 추가 인자 | `block_page`, `relation_page`, `warning_page` (각 20개), `before` (선택 이력 20개씩) |
| 비교 버전 | `moa-school-review-compare-v1` |
| 비교 데이터 | 구역 전후·변경 필드, 관계 전후 근거, 검수 시점 메타데이터, 파일 목록·경고·base hash |
| 조회 쓰기 | DB·원본 객체·분석 캐시·작업 큐·검수 이력·승인에 쓰지 않음 |
| 이후 수정/재변환 | 같은 pin·페이지의 비교 JSON은 유지; 선택용 최근 이력 목록은 늘어날 수 있음 |

페이지 이동은 양쪽 선택을 유지한다. 이력 선택 목록은 원본 + 현재 이력 페이지 20개 + 선택한 두 버전(최대 23개)이다.
더 이전 목록에서도 현재 선택을 잃지 않는다. 새 두 버전을 제출하면 내용 페이지를 1쪽으로 돌아간다.

빈 pin·중복/미지정 인자·범위 밖 페이지/커서는 400, 다른 학교/수신/변환에 속한 검수나 없는 이벤트는 404,
로그인 없음/회원 권한 회수는 401, 자동 분석 hash/블록 목록 불일치는 409로 거부한다.
누락된 선택을 최신 버전으로 임의 대체하지 않는다. 같은 학교 reader는 읽을 수 있으나 이 경로는 쓰기를 제공하지 않는다.

## 안전성·자원 제한

- 모든 원문·검수 사유·파일명·위치·관계·URL 속성을 escape한다. 문서 markup을 실행하지 않으며 외부 자산을 로드하지 않는다.
- 기존 `private, no-store`, `nosniff`, CSP·세션 보호를 유지한다. 비교 URL의 학교/사용자 필드로 권한을 정하지 않는다.
- 쿼리는 최대 10개 필드, pin은 1–160자, 내용 페이지는 실제 페이지 수 내, 이력 커서는 비음수 SQLite 정수 범위다.
- 텍스트 표시는 선형 공통 접두/접미 비교이며, 반복 문자열에 이차 시간 편집 거리 알고리즘을 적용하지 않는다.
- 기존 원분석/검수 크기 제한을 유지하고 페이지별 JSON 20MiB, HTML 누적 32MiB를 넘으면 실패한다.
  한도를 피하려고 원문을 조용히 잘라 정상 결과로 표시하지 않는다.
- 모델·학습·OCR·재파싱·추가 수집·운영 승인이나 새 배포 경로를 만들지 않았다.
