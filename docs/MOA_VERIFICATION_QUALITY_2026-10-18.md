- 날짜와 시간이 붙어 정규식에서 사라지던 문제를 수정했다. 짧은 숫자 날짜, 오전/오후,
  시간의 0 채움, 금액 쉼표·공백, `개`/`과목`을 처리한다.
- 렌더러가 정리하기 전의 원래 표 행을 따로 보존한다. 학과·교실 헤더를 읽는 별도 검사기로
  `연번–학과–교실` 연결을 대조한다. 좌우 반복 6열을 단일 3열 목록으로 바꾸는 경우도 검사한다.
  같은 렌더러 오류가 원문 비교 입력에 복사돼 통과하던 경로를 차단했다.
- 연결 개수·중복·연번·학과·교실을 함께 비교한다. 표 앞의 조건, 제목, 각주, 병합 문맥의
  누락도 보류한다. 의미를 인식하지 못하는 표는 기존 행·셀 비교를 적용한다.
- 규칙 판정, R1 원판정, 결합 판정을 분리한다. 규칙 불일치는 모델의 `preserved`로 덮지 않는다.
  모델 누락·토큰 한도·문맥 부족과 브라우저 오류도 검수 대상으로 남긴다.
- 모델 입력에는 독립 정답이나 규칙의 정답 힌트를 넣지 않았다. 추론 전용 실행기는 R1 파일 해시,
  입력·출력 해시, 중복 ID, 시간·자원·장치 잠금, 저장된 모델 등록 정보 보존을 확인한다.
- 긴 표를 한 행씩 다시 검사할 수 있게 했다. 헤더·병합 문맥·각주와 셀 전체를 유지한다.
  셀을 자르거나 일부만 검사하고 전체 성공으로 표시하지 않는다.

새 동작은 실패 회귀 테스트를 먼저 확인한 뒤 구현했다.
