## 1. 오탐을 줄이면서 보존한 검사

`moa.scoped-content-gate.v4`는 고정된 기존 `verification.py`를 변경하지 않는 시험용 어댑터다.
유일한 의미 앵커(신청 마감·참가 비용·명시적 주어·독립 조건문)와 **문장 전체 토큰의 1:1 일치**가
확인된 문장만 대응시킨다. 실제 DOM 문장을 이동할 뿐 원문 값을 복사하지 않는다.
일반적인 문자열 정렬이나 문장 집합 비교는 하지 않는다.

다음은 엄격한 비교를 유지한다.

- 날짜·시간·금액·선택 수·부정/예외·단위·각주·누락·중복.
- 순번 절차, 위 조건/첫 번째/전자·후자 같은 참조, 다른 필드의 각주가 제약하는 순서.
- 학과–교실 관계·행 키. 6열→3열은 명시적으로 반복된 연번/학과/수업교실 헤더와 유효한 연결이 있을 때만 허용한다.
- 원래 6열 표의 첫 행을 가리키는 각주가 있으면 단일 목록의 첫 행과 같다고 간주하지 않는다.
- 미확인 6열 표·병합 관계는 정상 재배치로 자동 확정하지 않는다.

기존에 노출된 128문항은 회귀시험으로만 재실행했다. 정상 오탐은 8/32→0/32,
중요 오류 검출은 80/80 유지, 근거 부족 16/16, 전체 128/128이다. 새 블라인드가 아니다.

## 3. `source_complete`와 근거 부족

`moa.evidence-inventory.v2`에서 다음을 별도로 계산한다.

| 차원 | 확인 근거 | 확인하지 못하면 |
| --- | --- | --- |
| 원본 전체 | 원본 SHA·무결성·예상 페이지와 실제 확보 페이지 목록 | 부족 또는 미확인 |
| 검증 구역 | 필요한 문맥 ID·실제 제공 문맥·원문 블록과 DOM 참조 | 부족 |
| 표 문맥 | 실제 비교 표 블록에 연결된 헤더·각주·병합 관계 목록 | 부족 또는 미확인 |
| 파일 역할 | 해당 원본/리비전에 묶인 사람 역할 확인 또는 합성 저작 근거 | 미확인 |

`source_complete`는 해당 구역과 표 문맥의 완전성만 나타낸다. 원본 전체/파일 역할까지 대신 보증하지 않는다.
네 차원 중 필요한 증거가 부족하거나 미확인이면 종합 결과는 검수 필요다.
합성 페이지 ID는 저작 원문/변형 명세의 인벤토리이며, 실물의 페이지 확보를 증명하는 자료로 사용하지 않았다.
빈 표 목록에 `complete=true`만 붙여 실제 비교 표를 통과시키는 경우도 차단한다.
모델 정답·예측을 provenance에 넣지 못하며, 규칙으로 분류한 근거 부족을 LAYA 정답률에 포함하지 않는다.
