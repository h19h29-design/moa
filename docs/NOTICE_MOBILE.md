# 안내문 업로드·모바일 변환·검수

## 사용 방법

1. https://moa.h19h19.com 에서 기존 검수 암호로 로그인한다. 암호 값은 문서·채팅·Git에 기록하지 않는다.
2. 안내 HWP/PDF 등을 **안내문**으로 올리고, 별도 신청서·참고자료는 **함께 첨부**에서 추가한다.
3. 파일마다 **모바일 변환 / 원본 첨부 유지**를 확인한다. 원본 첨부는 이후에도 추가할 수 있다.
4. 혼합 문서는 작성용 서식 시작 구역을 지정하고 경계를 확인한다. 불명확하면 보류한다.
5. **모바일 HTML 생성**을 누른다. 영속 jobs 대기열에서 처리되며 재기동 후 이어진다.
6. 원본 다운로드·이미지/PDF 보기와 읽을 수 있는 모바일 결과를 대조한다.
7. 본문, 표 내용·헤더·병합 좌표·행/열·단위·각주·표현을 수정한 뒤 **수정 저장 후 재검토**한다.
8. 원문 대조·이용권한·개인정보 확인 후 **승인**한다. 확인 전에는 **보류: 아직 미확인**으로 남길 수 있다.
9. HTML 또는 **HTML + 실제 원본 ZIP**을 내려받는다. ZIP을 풀고 index.html을 열면 실제 첨부도 함께 열린다.

지원 상태·검수 상태를 혼동하지 않는다. 작업 done은 처리가 끝났다는 뜻이며, 모든 문서를 읽었다는 뜻이 아니다.
미검수 결과는 미검수 표시가 유지된다. 보류는 오답으로 내보내지 않는다.

## 지원 범위

| 입력 | 처리 |
|---|---|
| HWP5 (비암호화) | 문단·배치 표·중첩 표·셀 병합 및 본문 순서 추출 |
| HWPX / DOCX | 로컬 XML 표·본문 추출. 복잡한 중첩/머리글/배치는 대조 필요 |
| 텍스트 PDF | 글자·표 추출. 표 병합·읽기 순서는 대조 필요 |
| HTML | 실행 코드를 제거하고 문단·중첩 표·신청 링크 텍스트 보존 |
| 이미지 / 스캔 PDF | needs_vision. 원본 보관, 변환 완료로 표시하지 않음 |
| 암호화 HWP / 구형·미지원 문서 | needs_parser 또는 parse_error. 원본 보관 |
| 작성용 서식·참고 TXT/XLS/XLSX 등 | 실제 원본 다운로드. 별도 신청 기능으로 만들지 않음 |

페이지 일부만 제공된 자료는 incomplete로 남긴다. 제공되지 않은 내용을 생성하지 않는다.
원문에서 읽히지 않은 개체·도형·수식·복잡한 페이지 배치는 실제 원본에서 확인해야 한다.

## 원본·추출·검수 버전

- objects의 원본 SHA-256 파일은 변경하지 않는다. 동일 파일은 물리 객체를 공유한다.
- 기존 notices/cases 및 수집 실적은 보존한다. 업로드는 mobile_notices에 저장되어 일일/백필 실적에 포함되지 않는다.
- mobile_revisions는 추출 버전·파일 역할·모바일 구조·후보 HTML을 함께 기록한다. 과거 버전은 보존한다.
- mobile_reviews는 확인한 revision_id, 검수자, 승인/보류/반려/취소, 사유·메모를 기록한다.
- 파일 역할·첨부·내용·파서 결과가 바뀌면 새 후보가 된다. 이전 화면에서 새 버전을 승인할 수 없다.
- 사람 수정본을 미리보기·HTML·ZIP에 동일하게 사용한다. 기존 표 검색도 correction을 반영한다.

## 승인 사례 참고

승인되고 현재 유효한 비평가 버전에서 **헤더 의미·병합 관계에 따른 표 표현 방식**만 검색한다.
현재 파일의 날짜·금액·학교명·신청 링크·셀 내용을 다시 읽어 렌더링한다. 과거 사실값을 복사하지 않는다.

변환 이력의 recommendations에 참고한 notice_id/revision_id/block_id/rule_id를 기록한다.
승인취소·보류·수정된 사례는 다음 검색과 `learning/mobile-approved-rules.jsonl`에서 즉시 제외한다.
평가용 업로드 체크 또는 기존 eval 표 사례를 포함한 수집 자료도 검색·규칙에서 제외한다.

좌우 반복 6열 표는 **동일한 연번/학과/수업교실 헤더, 연속 번호, 병합·빈칸 조건**을 검증한 후
한 3열 목록으로 정리한다. 행/열 수만으로 양식을 합치지 않는다.

이는 승인 사례에 따른 구조·레이아웃 추천이며 모델 가중치 훈련이 아니다. 외부 AI 전송·유료 호출·파인튜닝을 구현하거나 실행하지 않았다.

## 보안·운영

- 웹 로그인 필요: 원문·후보 HTML·objects·다운로드를 포함한 모든 자료.
- 로그인 암호는 MOA_REVIEW_TOKEN 환경변수에서 읽고 URL·로그로 내보내지 않는다.
- HTTPOnly/SameSite=Strict 세션, HTTPS Secure 쿠키, CSRF·Origin 검사, 로그인 요청 제한.
- 고정 HTML 컴포넌트와 이스케이프, CSP, private/no-store, 파일명/시그니처/용량 검증.
- 파일당 25MB, 총 50MB, 10개 제한. 파서는 별도 CPU·메모리 제한 프로세스에서 실행한다.
- 기존 한국시간 04:00, 50/50/20 목표·백필과 robots/TLS/IP 요청 정책을 유지한다.
- NAS 데이터는 `/volume2/moa/data`이며 원문·DB·키를 Git에 넣지 않는다.

모바일 변환 worker는 review 서비스에 포함되며 collector의 수집 스케줄과 별도로 처리한다.
review 서비스를 재시작하면 중단된 모바일 jobs를 이어서 처리한다.
