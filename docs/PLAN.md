# 구현·검증 순서
1. 테스트: 날짜별 quota, 중복/정정본, 동시 실행 잠금, HTML 병합 셀, HWPX, 학교 샘플링,
   NEIS 샘플 거부, URL/내부망 차단, 본문 판독 실패, 승인 분리, 수집 실패 후 보충.
2. 저장소/설정/원자적 저장/보고서 구현.
3. 안전한 GET 클라이언트/robots/NEIS 목록/게시판 파서 구현.
4. PDF/HWPX/HTML 추출, 패턴 후보 DB/검색/승인 데이터 내보내기 구현.
5. 일일 파이프라인과 스케줄러, CLI, Docker/NAS 설치 스크립트.
6. pytest 및 문법/설정 검증, 실제에 가까운 모의 end-to-end 검증.
7. 코드 검토 후 기존 기본 브랜치를 읽고 강제 덮어쓰기 없이 커밋·푸시.
8. 원격 SHA/파일 해시를 재확인하고 설치·실행·한계를 안내.
