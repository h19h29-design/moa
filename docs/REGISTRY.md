# 학교목록·지역별 실적

자동 목록은 NEIS schoolInfo를 전체 페이지 순회하여 생성한다. API 키는 NAS .env에만 보관한다.
전국 목록 동기화는 7일 간격이다. 중간 실패/반복 페이지/샘플 응답에서는 기존 목록을 덮어쓰지 않는다.
기존 유효 목록이 있으면 경고를 남기고 계속 사용한다.

정식 API 사용이 불가한 환경에서는 허용된 학교목록을 수동 JSON으로 제공할 수 있다.
`/volume2/moa/data/registry/schools.json` 형식:

```json
{
  "schema_version": 1,
  "source": "operator-maintained registry",
  "synced_at": "2026-09-21T04:00:00+09:00",
  "schools": [
    {
      "office_code": "B10",
      "office_name": "서울특별시교육청",
      "school_code": "실제학교코드",
      "school_name": "실제학교명",
      "school_kind": "초등학교",
      "home_url": "https://실제학교홈페이지/"
    }
  ]
}
```

위 예시는 실제 학교 레코드가 아니다. 전국 수집에는 각 지역의 실학교 목록이 필요하다.
수동 목록도 7일이 지나면 NEIS 갱신을 시도하지만, 키/네트워크 문제 시 기존 목록을 사용하고 경고한다.
교육청 이름/코드는 원본 목록을 따른다. 사용자 정의 목표는 `.env`의 서울/기타 두 값으로 지정한다.
한 지역에 접근 가능한 자료가 부족하면 `shortfall`로 기록한다.

동일 문서의 출처가 여러 지역일 때 원본은 한 벌이며, 최초 수집 지역만 신규 건수에 포함한다.
다른 지역의 출처 정보는 sightings에 남기고 다른 고유 문서를 추가 탐색한다.
최신성은 게시일·수집시각이 다르다는 점에 유의한다. '오늘 수집'이 '오늘 발행'을 의미하지 않는다.
